# TU IA LOCAL

*Creado por **SecTF Lab***

## Requisitos

- Windows 10/11 con `winget` (viene de serie en Windows moderno).
- No hace falta tener Node.js ni Ollama instalados de antemano: el asistente los comprueba
  y los instala él solo si faltan.

## Para usuarios finales (sin conocimientos técnicos): "Asistente de IA"

Descomprima el .ZIP , dentro de dentra carpeta, encontrará un "AsistenteIA.exe"
ejecutelo, este instalará todo lo necesario para funcionar.
    - instalará Node.js
    - instalará ollama

Cuando finalice la instalación, se abrirá una pagina web en local,
hay que darle a "iniciar Servicio de Ollama" una vez iniciado hay 
que elegir un asistente IA de la lista que le sale a continuación.

Una vez instalado solamente debe elegir "Iniciar conversación"
